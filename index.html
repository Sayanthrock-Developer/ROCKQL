Open-source query language

Readable pipelines.
Standard SQL.

RockQL lets you describe data transformations as a clear top-to-bottom pipeline, then compile that source into SQL.

View on GitHub Read the docs

Readable

Queries follow the data flow instead of forcing every transformation into SQL clause order.

Composable

Build a query from small pipeline operations such as filter, select, derive, sort, and take.

Portable

Keep the language separate from SQL generation so database dialects can evolve independently.

from employees
filter salary > 50_000
derive yearly_salary = salary * 12
sort {-yearly_salary}
take 10
